# Bundled Ringtones

The bundled ringtone presets are intentionally numbered as `ringtone-1.ogg`, `ringtone-2.ogg`, and so on. The labels in Foundry match those file names so users can choose by listening instead of by genre.

The library contains a mix of project-provided generated tones and previously bundled public-domain source audio that has been trimmed, downmixed to stereo, and encoded as OGG for Foundry playback.

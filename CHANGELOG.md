# Changelog

## 1.0.2

- Added GM drag-and-drop support for Actors in the contact manager.
- Dropping an Actor from the sidebar or a compendium now creates a contact from the Actor's name and portrait, then opens it for editing.
- Added a visible actor drop zone and active drag styling to the contact manager.

## 1.0.0

- Added GM-managed commlink contacts with portrait, handle, message, and call volume.
- Added selected-recipient calling with player pills and GM self-test support.
- Added incoming phone UI with answer/dismiss status reporting.
- Added player-selected ringtone preferences with bundled OGG ringtone library.
- Added selectable phone frame styles, including a no-frame option.
- Added GM-only welcome tutorial and scene-control shortcut settings.
- Verified module manifest compatibility for Foundry VTT v13 and v14.
